Tips for Finding the Right Group

  • Read the description. Each listing has a short description of what the group is about. Join groups whose description matches what you want.
  • Check the language. Listings show the group’s main language so you do not join a chat you cannot follow.
  • Start with one or two. It is better to be active in a couple of good groups than to join twenty and mute them all.
  • Respect the rules. Every group has its own norms. Read the pinned message when you join, introduce yourself if that is the culture, and do not spam.

Keeping the Directory Clean

We re-check invite links on an ongoing basis. Groups with expired or revoked links are paused until the admin provides a working invite. Groups reported for spam, scams, or illegal activity are investigated and removed if the report checks out. This keeps the gallery full of groups you can actually join — not a graveyard of dead links.

Found a dead link? Report it — it takes ten seconds and helps everyone.
